도원(Dowon) 개인정보처리방침

시행일: 2026년 10월 15일

도원은 '또다시'(인스타그램 @tto.dasi) 채널 주인 1인이 쓰는 내부 게시 도구입니다. 도원은 유튜브 API 서비스(YouTube API Services)를 사용해, 채널 주인이 직접 확인하고 승인한 영상을 채널 주인의 유튜브 채널에 올리고, 그 영상의 조회수를 읽습니다.

  • 모으는 정보: 채널 주인 본인이 올린 영상의 번호·주소·조회수만 저장합니다. 다른 사람의 개인정보나 다른 채널의 데이터는 모으지 않습니다.
  • 쓰는 목적: 채널 주인이 자기 영상의 성과를 확인하는 데만 씁니다. 제3자에게 제공하거나 판매하지 않습니다.
  • 보관과 삭제: 채널 주인이 언제든 삭제할 수 있습니다. 구글 계정 권한 설정에서 도원의 접근을 해제하면 모든 API 호출이 즉시 멈춥니다.
  • 함께 적용되는 정책: 도원은 YouTube API Services를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
  • 문의: 인스타그램 @tto.dasi 메시지

Dowon Privacy Policy

Effective date: October 15, 2026

Dowon is an internal publishing tool used only by the owner of a single channel ("또다시", Instagram @tto.dasi). Dowon uses YouTube API Services to upload videos that the owner has reviewed and approved to the owner's own YouTube channel, and to read the view counts of those videos.

  • Data collected: only the video IDs, URLs and view counts of the owner's own uploads. No personal data of other people and no data of other channels is collected.
  • Use: solely to show the owner the performance of their own videos. Data is never shared with or sold to third parties.
  • Retention and deletion: the owner can delete the data at any time. Revoking Dowon's access at Google Account permissions stops all API calls immediately.
  • Applicable policies: by using YouTube API Services through Dowon you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
  • Contact: message @tto.dasi on Instagram.
