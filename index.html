YouTube API 서비스를 사용합니다 · Uses YouTube API Services

도원은 YouTube API 서비스(YouTube Data API v3)를 사용해, 채널 주인이 직접 확인하고 승인한 짧은 세로 영상을 채널 주인 본인의 유튜브 채널 @tto_dasi에 올리고, 그 영상의 조회수를 읽습니다. 도원을 쓰면 YouTube 서비스 약관에 동의하는 것이며, Google 개인정보처리방침이 함께 적용됩니다.

도원이 하는 일

  1. 정부 지원금·제도의 대상, 금액, 신청 마감일을 공식 공고문에서 확인해 짧은 글과 카드뉴스로 정리합니다.
  2. 채널 주인이 업무 화면에서 글·영상을 하나씩 보고 직접 승인합니다. 승인하지 않은 것은 올라가지 않습니다.
  3. 승인한 그대로의 영상을 채널 주인 본인의 유튜브 채널에 쇼츠로 예약해 올립니다.
  4. 올린 영상의 조회수를 읽어 업무 화면에서 성과를 확인합니다.

About Dowon

Dowon is a private, internal publishing tool used only by the owner of the "또다시" channel. It turns fact-checked Korean government-benefit information into short vertical videos. The owner reviews and explicitly approves each video before Dowon uploads it, via the YouTube Data API, to the owner's own channel (@tto_dasi) and reads the view counts of those videos. Dowon is not offered to other users and does not access other users' or channels' data.
